# Bundled engine marks

Original PNG bytes extracted from the existing public SVG wrappers; artwork is unchanged. Imported with Vite `?inline` so each built component contains its image data, independent of public asset URLs and caches.

- `stockfish.png`: official Stockfish fish icon from https://github.com/official-stockfish/stockfish-web/blob/master/static/images/logo/icon_128x128.png, embedded without pixel changes in a local SVG wrapper for consistent sizing (retrieved 2026-09-10; upstream PNG SHA-256 `DD6475C967CA6F32DAB76F7B23446020B76549CD5EA70B4F51BE7C5C1C5D40B7`; upstream website repository is MIT licensed).

- `lc0.png`: official LCZero small-format mark from https://github.com/LeelaChessZero/lczero.org/blob/master/static/favicon.ico, exported losslessly to PNG and embedded in a local SVG wrapper with nearest-neighbour scaling (retrieved 2026-09-10; upstream ICO SHA-256 `A98B31B9E78F853D79AFF26EAFB6756F2ACCE68AD8DE02F03635E699CE0A3633`; upstream does not state a separate logo licence).

These marks identify the corresponding engines and do not imply endorsement. LCZero has no separately verified artwork permission grant.
