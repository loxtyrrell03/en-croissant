Scope: En Croissant saved-card readers and existing background migration. No owner-data scan, runtime change or UI redesign.

## Reproduced failure

The historical adapter/core at `a31f951318e98c3d09ffcd8260da1e4d57b335da` actually emits a high-confidence **Discovered Attack** for the constructed Re8+ exchange recorded in the companion receipt. Current classification rejects that claim because a branch had borrowed an unrelated later capture. Nevertheless, current saved-array readers displayed **What you missed: Discovered Attack**, counted it as one occurrence, offered it in theme practice, and rendered the obsolete proof and payoff. Nature correctly remained unknown, creating a visible contradiction.

A second historical record accused the player of missing a fork they actually played. Fresh classification correctly preserves neutral **Both moves create this fork** context.

This was not merely a first-render flicker. Workspace waits 450 ms before motif migration, suspends it during practice and retains old state on failure. Raw readers ignored the saved version throughout that interval. Two timeline reads also bypassed the root getters entirely.

## Shared contract

A cheap, atomic stored-classification reader now requires the exact current `motifClassifierVersion` and valid arrays under the existing saved-card schema. Both root arrays are required: all current classifier constructors emit them. Timelines remain optional; absence falls back to the same valid record's roots, while explicit empty timelines stay empty.

Missing, old, future or malformed records abstain together across allowed/missed getters, counts, practice filters and timelines. They do not trigger synchronous tactical searches. Validation inspects only version and motif fields, and is cached under the existing immutable metadata/array update convention.

The existing asynchronous migration restores current evidence. It also repairs malformed current-version records; Workspace no longer discards those repairs merely because the version string is unchanged. Raw lines, annotations, notes and review progress are retained. Successful current empty results remain valid and do not cause repeated migration.

Current genuine proofs and neutral retained mechanisms survive unchanged. No empty-result-to-positional conversion, weaker proof rule or global theme suppression is introduced. During suspended or failed migration, an unavailable current theme is left unclassified rather than presented as an old verified cause.
