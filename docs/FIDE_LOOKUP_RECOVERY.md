# FIDE search recovery

The desktop and phone import pickers distinguish a failed lookup from a confirmed empty result. Errors have an adjacent Retry search action. Clearing, shortening, disabling or unmounting the picker abandons its pending request; replacement queries cannot select old suggestions. Desktop results open only while the input has focus. Suggestions retain complete names, labelled rating types and FIDE IDs, and the desktop list uses its available viewport height.

Desktop lookups use the existing shared Lichess request lane, including its spacing and rate-limit cooldown. Direct lookup and ranked search share a bounded cache and pending request. Cancelling one reader preserves other readers; cancelling the last reader abandons the transport. The eight-second deadline includes queueing and body reads, including a provider promise that ignores abort. Only successful responses and confirmed misses are cached. The existing full-career year helper and tolerant name ranking remain in the common player model. The unused older prep picker was removed after checking all source consumers.

The PC search service retains its existing success/miss TTLs, photo metadata and name ranking. It now limits the cache to 128 entries, serializes searches with 500 ms spacing, respects at least a minute after HTTP 429, validates response shape and exact numeric identity, and bounds queued/body reads to eight seconds. A disconnected HTTP reader cancels only its own search subscription. The phone transport validates the PC response and has a ten-second deadline, allowing the PC's eight-second failure to arrive first. These are process-local request lanes; they are not a cross-process traffic coordinator.

Both import forms use the same identity resolver. A supplied ID must resolve to that exact player; conflicting IDs, missing identities and failed ID lookups prevent import. Duplicate exact-name matches never silently pin the first ID. Full-name imports without an ID remain supported when optional public-mirror enrichment fails. An explicit import year remains authoritative; otherwise a resolved birth year reaches the same request. ID autofill is cancelled by editing, selecting another player, starting preflight or unmounting. Stop FIDE search cancels preflight before a native collection or PC job starts. Existing collection, conversion, job cancellation and saved-data behavior remain separate.
