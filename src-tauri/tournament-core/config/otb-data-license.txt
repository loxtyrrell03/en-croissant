Novelty transforms the official monthly PGNs into a player-name and FIDE-ID
search index with compressed game text. Archive URLs and game text are retained.
This data is offered under CC BY-SA 4.0 independently of Novelty application code.
Coverage describes the included archives, not all OTB games or all import sources.
